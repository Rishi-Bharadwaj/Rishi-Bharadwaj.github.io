This is a template. Files in `_drafts/` are never published.

To publish a post, copy this file into `_posts/` and rename it to
`YYYY-MM-DD-short-title.md`, for example `_posts/2026-10-20-why-kantian-equilibrium.md`.
The date in the file name becomes the post date.

Write in plain Markdown. A few things you might need:

## A heading

Regular paragraphs, *italics*, **bold**, [a link](https://arxiv.org/).

- bullet lists
- work like this

Images go in `assets/` and are linked like this:

![A cat on a bench](/assets/cats/example.jpg)

Math is not enabled by default. Ask if you want it turned on for paper notes.
